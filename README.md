# Stroke data

Stroke data and pronunciation recordings used by a Chinese and Japanese handwriting app, published here so anyone can copy it, as its licence asks.

Each folder holds one set of data, with its own licence and a README saying where it comes from and what was changed:

- `chinese/`: Chinese characters (simplified and traditional), from Make Me a Hanzi: stroke data (`strokes.js`, Arphic Public License) and how characters break into parts (`parts.js`, GNU LGPL); pronunciation recordings (`audio/`, `audio.js`), from audio-cmn (CC BY-SA, see `AUDIO-LICENSE.txt`) and Lingua Libre (CC0).

The data drives [Hanzi Writer](https://github.com/chanind/hanzi-writer): for each character, the stroke outlines (`strokes`) and their centre lines (`medians`), in Make Me a Hanzi's format.
